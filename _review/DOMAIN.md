# Domain and email handoff
Recommended first choice: koredeadene.com; consider koredeadene.ca, korede.design and koredeadene.design if the preferred name is unavailable. Availability and prices have not been verified. Compare the first-year and renewal prices in CAD, privacy terms, eligibility, transfer fees and auto-renewal at the registrar before paying. Do not change the current Pages source.

1. Register only after choosing the name and budget. Enable account MFA and renewal reminders. In your GitHub account Settings → Pages, verify ownership with the exact TXT name/value GitHub provides. Preserve the verification record.
2. Add the verified custom domain in this repository’s Settings → Pages. For an apex address use the current Pages A/AAAA records in GitHub’s official guide or supported ALIAS/ANAME service. Point the www CNAME to korede1000.github.io (no protocol or repository path). Avoid wildcard DNS. Preserve unrelated mail and verification records.
3. Once DNS resolves, confirm the primary domain, alternate host redirect, certificate and Enforce HTTPS. Check root, a project page, images and a nested missing URL on the custom host. Retest the old Pages address. No CNAME has been added on this branch.
4. Replace the existing Pages base in canonical and Open Graph tags, social image URLs, JSON-LD, sitemap.xml, robots.txt and the base element in 404.html. Verify the domain in Search Console with the supplied TXT record, submit the new sitemap and inspect the home page. On a project subpath the repository’s robots.txt is not the host-root robots file.
5. Optional domain email: choose a provider only after approval, add its MX/SPF/DKIM/DMARC records, test sending and receiving, then update public contact details and the mailto composer together.
